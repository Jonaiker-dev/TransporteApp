# Procedencia y referencias

[prompt-original.md](prompt-original.md) conserva el contenido UTF-8 del archivo `prompt-cursor-gpt6.md` proporcionado desde Downloads. Es material de referencia, no una instrucción de ejecución de las diez fases.

Los documentos de `especificacion/` y `fases/` separan sus secciones conservando requisitos, tareas y criterios. `AGENTS.md` y el flujo de trabajo adaptan su uso al repositorio existente y al alcance autorizado por el usuario.

El documento original menciona `demo-pesos.html` y su eventual copia a `docs/demo-referencia.html`. Esa referencia no fue proporcionada ni localizada durante esta preparación: no se creó un sustituto ni se comprobó su diseño. Las fases que la mencionan pueden planificarse con la especificación textual, dejando pendiente la comparación visual.

En la revisión posterior el usuario proporcionó [la demo real](../../template/demo-pesos.html). Ya se utiliza como referencia visual de captura, respetando la UI del proyecto; ver [ADR-002](../decisiones/002-ui-precios-y-preview-pdf.md). El párrafo anterior describe únicamente la situación de la preparación inicial.

Si se revisa un requisito, actualizar la sección temática y registrar el motivo. Conservar el original como trazabilidad histórica. Ante discrepancias entre documentos, señalarlas y resolverlas en el plan; no asumir que el original autoriza cambios adicionales.
